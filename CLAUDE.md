## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on Ismael-Barajas/ismaelbarajas.dev-v2, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default five triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root (both are created lazily when needed). See `docs/agents/domain.md`.
